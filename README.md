# 📝 Notes App

A clean and responsive Notes App built with Flask and SQLite.

## Features

- ➕ Add Notes
- ✏️ Edit Notes
- 🗑️ Delete Notes
- 🔍 Search Notes
- 📌 Pin / Unpin Notes
- 🕒 Created & Edited Timestamps
- 🎨 Responsive UI with CSS

## Tech Stack

- Python
- Flask
- SQLite
- HTML
- CSS

## Run Locally

```bash
pip install flask
python app.py
```

Open:

http://127.0.0.1:5000
